# Describe Your Ex in One Word

Entry for the make.fun bounty
[u-puan-describe-your-ex-in-one-word-9fc6ebe7](https://make.fun/bounty/u-puan-describe-your-ex-in-one-word-9fc6ebe7).

`main.py` (Python 3, standard library only) writes one word to
`/output/entry.txt`:

> **Recalled**

The word is a one-word verdict on a former partner: an ex remembered,
and a faulty product pulled back by the manufacturer. One word, no
punctuation tricks, no caption needed.

Run it:

```sh
python3 main.py
cat /output/entry.txt
```
